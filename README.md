## 🌟 Key Features

- 🖤 **Modern Dark Obsidian Interface**: Clean, distraction-free UI with custom theme options (Dark Obsidian, Midnight Blue, Emerald, Crimson, and Classic).
- 🚀 **High-Speed Native Extraction & Compression**: Powered by official `UnRAR` and optimized multithreaded engines for maximum throughput.
- 📋 **Seamless Clipboard Copy & Paste**: Press `Ctrl+C` on any file inside the archive, go to your Desktop or any folder, and press `Ctrl+V` to extract immediately!
- ⏱️ **Real-Time Progress & Time Left**: Live byte-level tracking during extraction with dynamic ETA countdown and smooth progress bars.
- 🔒 **Encrypted Archive & Password Support**: Automatic detection of encrypted headers and password-protected archives with a dedicated dark password dialog.
- 🎮 **Gamer & Modder Friendly**: Optimized to handle modified DLLs, game fixes, cracks, and translations without false-positive blocks or NTFS attribute failures.
- 🪟 **Deep Windows Shell Integration**: Cascading right-click context menu (Open, Extract Here, Extract to folder, Add to archive) with custom high-res icons.
- 💯 **100% Free Forever**: No 40-day trial popups, no license nags, and no background tracking.

## 🚀 Installation & Setup

1. Download the latest installer from the **[Releases](https://github.com/zakariamahdjoubi03-cloud/Scar-Rar/releases)** page:
   - `SCAR RAR Setup.exe`
2. Run the setup wizard to install **SCAR RAR** and register file associations with Windows.
3. Enjoy an ultra-fast, modern archiving experience!
